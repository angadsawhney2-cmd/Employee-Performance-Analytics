# Employee Performance Analytics System

A Python-based employee performance analysis program developed as part of a team programming project.

The system analyses employee data and calculates several performance metrics, including productivity, attendance reliability, customer service performance, bonus eligibility and an overall employee performance score.

## Features

- Calculate employee productivity scores
- Calculate attendance reliability scores
- Evaluate customer service performance
- Determine employee bonus eligibility
- Calculate an overall employee performance score
- Classify employee performance results
- Menu-driven user interface
- Input validation to prevent invalid menu selections

## Performance Metrics

The program evaluates employees using information such as:

- Monthly sales
- Attendance percentage
- Overtime hours
- Customer satisfaction
- Age
- Department

The calculated performance metrics are added to the employee dataset during program execution.
